# PopChoice v0.1.0-beta.0

First beta release since `stretch-goals`.

## Highlights

- Replaced the fake quiz ending with a real recommendation pipeline: quiz submission now creates a recommendation record, queues background work, and opens `/results/[id]`.
- Added live result progress, failed/empty result states, and safer recovery when recommendation creation or polling fails.
- Added group mode for 2-6 people, including group result copy, group summary, and balanced recommendation output.
- Added accounts, registration/login/logout, delete account, password reset email via Resend, and automatic sign-in after registration.
- Added saved recommendation history for signed-in users, including filters, search, recommendation feedback badges, shared-result labeling, and owner-only rating.
- Added recommendation memory so user feedback such as "already watched" or "not interested" can be stored and used to reduce repeated picks.
- Expanded movie discovery with TMDB backfill, TMDB/local matching, movie metadata enrichment, and manual-review notes for ambiguous matches.
- Moved production to a Coolify Docker Compose stack on Hetzner with Postgres, Redis, workers, Bull Board, health checks, preview deploys, and Coolify deployment docs.
- Added public health/build metadata endpoints and browser console helpers for quick production debugging.
- Hardened API auth, environment validation, request limits, dependency health checks, and deployment diagnostics.
- Improved UI polish across quiz, results, account, translations, loaders, empty states, and navigation behavior.

## Deployment Notes

Coolify should set these production variables:

```txt
APP_VERSION=0.1.0-beta.0
APP_CHANNEL=beta
AUTH_SESSION_SECRET=...
API_KEY_HMAC_SECRET=...
VALID_API_KEYS=...
OPENAI_API_KEY=...
TMDB_API_KEY=...
POSTGRES_USER=...
POSTGRES_PASSWORD=...
POSTGRES_DB=...
REDIS_URL=redis://redis:6379
DATABASE_URL=postgres://...
RESEND_API_KEY=...
EMAIL_FROM=...
NEXT_PUBLIC_BASE_URL=https://pop-choice.shchilkin.dev
```

Optional build metadata:

```txt
APP_COMMIT_SHA=<git commit sha>
APP_GIT_BRANCH=development
```
