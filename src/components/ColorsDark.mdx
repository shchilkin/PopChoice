## Dark Mode Usage Guidelines

### Background Strategy

- **Primary**: `#0a0a0a` - Main page background (very dark)
- **Secondary**: `#262626` - Cards, input fields, elevated surfaces
- **Tertiary**: `#404040` - Hover states, subtle emphasis

### Text Contrast

- **High Contrast**: `#ededed` - Primary headings and important text
## Dark Mode Usage Guidelines

### Background Colors

- **Primary Background**: `hsla(0, 0%, 8%, 1)` - Main page backgrounds (very dark gray)
- **Card Background**: `hsla(0, 0%, 8%, 1)` - Content cards and panels
- **Secondary Background**: `#262626` - Input fields, subtle sections
- **Border**: `#404040` - Visible borders that work on dark backgrounds

### Text Colors

- **Primary Text**: `hsla(0, 0%, 94%, 1)` - Headlines, body text (very light gray)
- **Muted Text**: `hsla(0, 0%, 85%, 1)` - Helper text, labels (light gray)

### Interactive Elements

- **Primary Actions**: `hsla(14, 80%, 51%, 1)` - Darker orange/coral for dark mode CTAs
- **Alert States**: `hsla(54, 100%, 62%, 1)` - Same yellow works in both modes
- **Focus States**: Primary color for accessibility
- **Age Ratings**: HSLA-based semantic system optimized for dark backgrounds

### Component Adaptations

- **Borders**: Use `#404040` for visible divisions (upgraded from `#262626`)
- **Shadows**: Replaced with subtle borders or backgrounds
- **Overlays**: Use semi-transparent backgrounds for modals

### Accessibility in Dark Mode

- Higher contrast ratios are naturally achieved with the new HSLA values
- Focus indicators remain WCAG AA compliant
- Color meanings (accent=primary, alert=warning) are preserved
- Age rating colors maintain distinctiveness and readability

## Dark Mode Best Practices

1. **Use CSS Variables**: Always prefer `var(--accent)` over hardcoded values
2. **Test Contrast**: New HSLA system ensures proper readability
3. **Maintain Semantics**: Accent color replaces blue across both themes
4. **Consider OLED**: Very dark backgrounds (`8%` lightness) work well on OLED displays
5. **Smooth Transitions**: Theme switching should feel seamless with semantic tokens
