## Light Mode Usage Guidelines

### Background Colors

- **Primary Background**: `hsla(0, 0%, 100%, 1)` - Main page backgrounds (pure white)
- **Card Background**: `hsla(0, 0%, 100%, 1)` - Content cards and panels
- **Secondary Background**: `#f5f5f5` - Input fields, subtle sections

### Text Colors

- **Primary Text**: `hsla(0, 0%, 3%, 1)` - Headlines, body text (very dark gray)
- **Muted Text**: `hsla(0, 0%, 27%, 1)` - Helper text, labels (medium gray)

### Interactive Elements

- **Primary Actions**: `hsla(14, 100%, 57%, 1)` - Orange/coral accent for CTAs
- **Alert States**: `hsla(54, 100%, 62%, 1)` - Yellow for warnings
- **Focus States**: Primary color for accessibility
- **Age Ratings**: HSLA-based semantic system with proper contrast
