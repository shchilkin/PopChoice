# PopChoice

PopChoice is an **AI-powered movie recommendation engine** that uses OpenAI embeddings and vector databases to provide personalized movie suggestions based on user preferences.

This project was built as part of the **Embeddings and Vector Databases** chapter from "The AI Engineer Path" on [Scrimba](https://scrimba.com/the-ai-engineer-path-c02v).

## ✨ Features

- 🎬 **AI-Powered Recommendations** — Uses OpenAI embeddings for semantic movie matching
- 📊 **Interactive Questionnaire** — Collects user preferences through engaging questions
- 🔍 **Vector Search** — Lightning-fast similarity search with PostgreSQL pgvector
- 📱 **Responsive Design** — Works seamlessly on desktop and mobile
- 🧪 **Component Library** — Built with Storybook for consistent UI components

## 🛠 Tech Stack

| Layer       | Technology                                      |
| ----------- | ----------------------------------------------- |
| Frontend    | Next.js 15, React 19, TypeScript, Tailwind CSS  |
| AI/ML       | OpenAI GPT & Embeddings API                     |
| Database    | PostgreSQL with pgvector extension              |
| Movie Data  | TMDB (The Movie Database) API                   |
| Analytics   | Vercel Web Analytics                            |
| Testing     | Vitest, Storybook, Playwright                   |
